# ATHERION — Subsurface Hydro-Thermal Energy

One-page interactive website: a continuous 5-scene vertical world — Surface
Horizon, Subsurface Hydro Lab, Kinetic Turbine Core, Geo-Plasma Reactor, and
Restored Biosphere — built as a scroll-driven SVG experience.

Live site: https://orionrusel-rgb.github.io/atherion/

## Files

- `index.html` — page structure + all 5 scenes
- `style.css` — styles
- `script.js` — scroll engine, scene navigation, live telemetry UI

No build step — open `index.html` or visit the live link above.
